# archive/

Сюда переносятся модули, которые **временно не участвуют в активной разработке**, но сохранены как референс или для возможного будущего переиспользования.

## Содержимое

### `EclipsiaBuilder/`

Процедурный генератор Эликия (готическая столица), Берега, гор, собора и сопутствующих структур. Решением от мая 2026 выведен из активного скоупа — финальная карта будет строиться руками в `dev_flat` и `build` мирах через WorldEdit/FAWE/Axiom.

Код **не удалён** на случай:
- возврата к процедурным мини-данжам / рандомным руинам,
- переиспользования отдельных утилит (`RegionPainter`, `SimplexNoise`-обёртки, footprint-коллизии),
- повторного использования логики «городского полигона» (22-вершинная граница) для других зон.

См. подробнее в [`../docs/eclipsia-plan.md`](../docs/eclipsia-plan.md), раздел §1.

## Важно

- Архивные модули **не собираются** автоматически — `mvn` запускается только для активных модулей.
- Сюда **не коммитятся новые фичи** — если архивный модуль реактивируется, его сначала перемещают обратно в корень.
- История изменений архивных модулей сохранена в git-истории до момента перемещения.
