## 📋 Описание

Eclipsia - это комплексный RPG-сервер с уникальной системой навыков (эклипсов), боссами, структурами и полноценной прогрессией персонажа. Вдохновлен Path of Exile и классическими MMORPG.

---

## ✨ Основные возможности

### 🎭 Система персонажей
- **3 слота профилей** - создавайте разных персонажей
- **3 класса**: Воин, Лучник, Маг
- **Уникальные стартовые навыки** для каждого класса
- **Автосохранение** позиции и прогресса

### ⚔️ Система навыков (Эклипсы)
- **5 слотов активных навыков**
- **10 слотов поддержек** (по 2 на каждый навык)
- **Комбинирование эффектов** (AOE, мультивыстрел, взрыв)
- **Масштабирование от статов** (Сила/Ловкость/Интеллект)
- **Кулдауны и расход маны**

### 💙 Система маны
- **Отображение через Boss Bar** (вверху экрана)
- **Автоматическая регенерация** 2% в секунду
- **Цветовая индикация** состояния
- **Зависит от класса** (80/100/150 базовой маны)

### 👹 Боссы и мобы
- **Хранитель Врат** - первый босс с 3 фазами
- **Уникальные способности** боссов
- **Зоны спавна мобов** в структурах
- **Награды**: опыт, орбы, предметы

### 🏗️ Структуры мира
- **9 уникальных структур**: город, лагеря, арены, руины
- **Плоские миры** для полного контроля
- **Автоматическая генерация** через команду
- **Интеграция с WorldGuard** для границ

## 🚀 Быстрый старт

### Требования
```
✅ Paper 1.20.4
✅ Java 17+
✅ Multiverse-Core
✅ WorldGuard
```

### Установка

1. **Скопируйте плагины** в папку `plugins/`:
```
EclipsiaCore.jar
EclipsiaItems.jar
EclipsiaLobby.jar
EclipsiaSkills.jar
EclipsiaMobs.jar
EclipsiaBuilder.jar
EclipsiaPerks.jar
```

2. **Запустите сервер**:
```bash
java -Xmx4G -Xms2G -jar paper.jar
```

3. **Постройте структуры**:
```
/build all
```

4. **Готово!** Сервер готов к игре.

## 🎯 Геймплей

### Для игроков

1. **Создание персонажа**
   - Зайдите на сервер
   - Выберите класс (Воин/Лучник/Маг)
   - Получите стартовый навык
   - Начните приключение на Берегу

2. **Использование навыков**
   - Откройте меню: `/skills` или клавиша `I`
   - Вставьте навыки в слоты
   - Используйте ПКМ в хотбаре
   - Следите за маной (Boss Bar вверху)

3. **Первый босс**
   - Исследуйте Берег
   - Найдите арену Хранителя Врат
   - Победите босса
   - Получите награды и откройте путь в мир

### Команды игрока
```
/skills              - Открыть меню навыков
/character           - Управление персонажами
/stats               - Характеристики
/profile             - Профиль персонажа
```

### Команды администратора
```
/build all           - Построить все структуры
/boss spawn gatekeeper - Заспавнить босса
/giveskill <slot> <тип> - Выдать навык для теста
/mob spawn <тип>     - Заспавнить моба
/exp add <игрок> <кол-во> - Выдать опыт
```
