**Готовность к миграции:**

- SQLiteDataStorage полностью реализован

  - Фазы боя

- 🔜 **Награды:**
  - Уникальные предметы из боссов
  - Увеличенный дроп орбов
  - Достижения
- 🔜 **Таблица лидеров:**
  - Лучшее время прохождения
  - Топ игроков по уровню
  - Топ по орбам

### Тип хранилища: SQLite (ОБЯЗАТЕЛЬНО)
**Почему SQLite на этом этапе:**
- Данжи требуют хранения прогресса групп
- Таблица лидеров требует быстрых запросов
- Достижения требуют постоянного хранения
- PDC не справится с нагрузкой

**Новые таблицы:**
```sql
-- Прогресс данжей
CREATE TABLE dungeon_progress (
    party_id TEXT,
    dungeon_id TEXT,
    boss_kills INTEGER,
    best_time INTEGER,
    PRIMARY KEY (party_id, dungeon_id)
);

-- Таблица лидеров
CREATE TABLE leaderboard (
    player_uuid TEXT PRIMARY KEY,
    player_name TEXT,
    level INTEGER,
    orbs INTEGER,
    achievements INTEGER,
    last_update INTEGER
);

-- Достижения
CREATE TABLE achievements (
    player_uuid TEXT,
    achievement_id TEXT,
    unlocked_at INTEGER,
    PRIMARY KEY (player_uuid, achievement_id)
);
```

**Миграция:**
- Команда `/data migrate` мигрирует все данные игроков
- Данные данжей создаются с нуля (нет истории)
- Переключение в config.yml: `storage-type: SQLITE`
